## 复现

### 缺少 randomUUID 的兼容回归

管理界面的 POST 幂等键优先使用 `crypto.randomUUID()`；该函数缺失时，使用 `crypto.getRandomValues()` 生成 16 字节并设置 UUID v4 的版本及 variant 位。没有可用的安全随机 API 时返回中文错误，不使用 `Math.random`。这只是请求幂等标识，认证会话及 CSRF 校验保持不变。

`tests/e2e/web.mjs` 通过 `context.addInitScript` 仅移除 `randomUUID`，保留原生 `getRandomValues`，也不修改 `isSecureContext`。loopback HTTP 页面的安全上下文标志仍为 true；脚本检查真实登录和创建 POST 成功、每次 POST 的幂等键符合 UUID v4 且不重复、创建请求仍带 CSRF。此项模拟缺少该函数，不替代实际 LAN HTTP 的非安全上下文验收。

另以 `tests/e2e/http-login.mjs` 实际访问部署配置中的 LAN HTTP 入口，未覆盖安全上下文标志或随机数API。真实浏览器确认 `isSecureContext=false`、`randomUUID` 不存在、`getRandomValues` 可用；修复前复现截图中的原错误，更新部署后登录POST携带合法UUID v4、HttpOnly会话创建、已导入账号目录读取和退出均通过，页面错误0。脚本仅在内存中读取本地令牌，不保存截图、浏览器状态或真实凭证；默认从项目 `secrets/admin-token` 读取。

同时已单独验证原生函数优先、全零及全 255 随机字节下的 UUID v4 位约束，以及随机 API 均缺失时的中文 `SECURE_RANDOM_UNAVAILABLE` 错误。

### 独立测试服务

先完成根目录依赖安装和构建。测试 Chrome 可以是本机的官方 Google Chrome，也可以显式使用官方 Chrome for Testing。其 Linux 动态库依赖应在测试环境中可用。

```bash
unset NODE_TLS_REJECT_UNAUTHORIZED

  node --import tsx tests/e2e/web.mjs --serve
```

此模式创建权限受限的随机临时数据目录、主密钥及随机管理员凭证，只打印凭证**文件路径**，不打印令牌。它不会调用 worker 或更新调度器，不会连接生产数据库，也不会启动受管容器；只对测试 Google 会话运行身份状态轮询。退出时删除自己创建的临时数据。`/__ui_qa__` 标记、人工会话及身份夹具路由仅在此测试入口中注册，不会添加到生产服务。

## 验证范围

这组检查验证管理界面和真实控制服务的配置、鉴权及队列交互。因为测试服务没有 worker，它**没有**验证独立浏览器容器的启动关闭、浏览器实际代理出口、VNC 连接、Cookies 持久化、快照恢复或真实浏览器更新。这些能力需要容器集成验收。
